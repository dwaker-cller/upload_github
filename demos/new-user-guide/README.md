# 达人端中文新手引导 Demo

该单文件静态原型用于验证达人端新用户的任务式引导体验。

## 覆盖场景

- 完善个人资料与了解社媒账号认证。
- 浏览机会、查看详情并提交报名。
- 跟踪报名进度与合作状态。
- 接受合作邀请。
- 提交产物，以及驳回后的修改与重新提交。
- 查看收益相关入口。

## 运行方式

直接用浏览器打开 [`index.html`](index.html)，或在仓库根目录运行 `python -m http.server 8000` 后访问 `/demos/new-user-guide/`。

本 Demo 完全离线，所有数据均为演示数据，状态在刷新页面后重置。它聚焦达人端练习流程，不包含广告主端实操页面。
